# TD_Whitelabelstorefront_FE_angularjs

Standalone Angular enterprise-storefront frontend for the
**White-Label / Multi-Tenant Storefront** project type — a real
multi-component app (tenant banner + product grid, real HttpClient
service), not a single bare component.

Not connected to any backend or React app by default. The paired
standalone backend lives in `TD_Whitelabelstorefront_BE_nodejs`, and
the React self-serve storefront in
`TD_Whitelabelstorefront_FE_reactjs`. The fully connected version
lives in `TD_Whitelabelstorefront_BE_nodejs_FE_reactjs_FE_angularjs-`.

See ARCHITECTURE.txt for build commands and module layout.

Branches: one per Angular version (16, 17, 18, 19).
